Before coding, inspect the reference plugins provided by the user in `docs/refs`:
1. `docs/refs/uvpackmaster_addon/uvpackmaster4/`: Industry-standard UV packing engine. Inspect `operator.py`, `box.py`, `geom.py`, `tdensity/`, `grouping.py`, `island_params.py`. Replicate its core packing strengths:
   - Heuristic 2D bin packing (MaxRects BSSF / Best Short Side Fit, Guillotine).
   - Island rotation optimization (test 90 deg, 45 deg, or free rotation to achieve minimum convex hull area).
   - Exact pixel padding and tile boundary margin relative to texture resolution.
   - Texel density normalization (equalizing UV area to 3D surface area across all islands before packing).
   - Multi-UDIM tile distribution (packing across tiles 1001, 1002, 1003...).
2. `docs/refs/ZenUV_5_2_0_0/ZenUV/`: Leading UV cutting and seam management toolset. Inspect `ops/`, `utils/`, `prop/`. Replicate its key workflows:
   - Mark seams by sharp dihedral edge angle (user-configurable angle threshold, e.g. 30, 45, 60 degrees).
   - Mark seams by Polygroup / SubTool boundaries (essential for ZBrush workflows).
   - Interactive 3D/2D seam cutting and unwrap (LSCM - Least Squares Conformal Maps or ABF angle-based flattening).
   - UV island segmentation from marked seams.

Implementation Architecture:
1. Core UV Engine (`src/uv/`):
   - `UVIsland.h`: Representation of UV islands, vertices, 2D polygons, bounding boxes, convex hulls, 3D surface area, and rotation transforms.
   - `UVCutter.h` / `UVCutter.cpp`: Dihedral edge angle detection, polygroup boundary seam extraction, seam tracking.
   - `UVUnwrapper.h` / `UVUnwrapper.cpp`: Conformal/planar flattening of cut charts into 2D UV coordinates.
   - `UVPacker.h` / `UVPacker.cpp`: Island segmentation, texel density equalization, rotation optimization, heuristic bin packing (MaxRects), UDIM distribution, non-overlapping placement with exact pixel margins.
